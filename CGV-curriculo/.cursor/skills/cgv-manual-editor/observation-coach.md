# Skill 1 — Observation Coach ⭐⭐⭐⭐⭐

Checks whether every comment actually helps the reader observe the text.

## Job

For each `>` you touch, ask: **Does this help the student notice something on the page?**

If it only explains, renames, or lectures — rewrite toward observation.

## Pass / fail

| Pass | Fail |
|---|---|
| Points at a visible change (subject, connector, contrast, delay) | Restates the clause in softer words |
| Makes the student look back at Scripture | Works even if the verse is hidden |
| Names what is *there* (or deliberately withheld *by the author*) | Supplies meaning the line does not carry |
| Short enough that the eye stays on the text | Crowds out the verse with explanation |

## Checklist

- [ ] Can I underline one short focus word that is actually on or about the page?
- [ ] If I delete this comment, does the student lose a *sight*, or only a *paraphrase*?
- [ ] Does the comment teach seeing — not conclude for them?
- [ ] Is grammar (if any) serving a misread risk — not a form tour?

## Rewrite moves

1. Cut the paraphrase opener (*El texto dice…* / *Aquí se menciona…*).
2. Point: *who acts / what hangs / what changed / what is still open*.
3. Stop before the sermon.

## Success line

The student says: **“I see that now.”**
