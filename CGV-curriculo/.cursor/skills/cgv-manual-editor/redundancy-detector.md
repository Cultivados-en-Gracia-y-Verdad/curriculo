# Skill 3 — Redundancy Detector ⭐⭐⭐⭐⭐

Finds comments that merely restate the clause or repeat earlier comments.

## Job

Cut dead weight.

If the student can get the same thing by rereading the verse, the comment is not helping.

## Pass / fail

| Pass | Fail |
|---|---|
| Adds a sight, seam, or pressure the verse alone does not shout | Renames the clause (*La esperanza no queda suelta…* on loop) |
| Distinct job from the previous `>` | Same shape / same opener as the last three comments |
| Earns its slide | Obvious information anyone already saw |
| One purpose | Mixed paraphrase + grammar + sermon |

## Common redundancy patterns

1. **Verse echo** — comment ≈ verse with synonyms.
2. **Triple worksheet** — only renames quién / qué / hacia qué with no path.
3. **Stock cadence** — every block starts *El texto…* / *El autor…* / *La línea…*.
4. **Equal attention** — tiny transitions get the same density as major turns.
5. **Repeated pressure closer** — *El autor no explica…* on every line.

## Checklist

- [ ] Delete test: if removed, is anything *observational* lost?
- [ ] Could this be 30% shorter without losing the one purpose?
- [ ] Does another `>` on this page already do this job?
- [ ] Is this transition over-commented?

## Rewrite moves

1. Delete obvious comments.
2. Merge two crumbs that say the same thing into one purposeful `>`.
3. Vary or cut stock openers.
4. Thin transitions; keep weight on major movements.

## Success line

Every remaining comment earns its place — none are decorative restatement.
