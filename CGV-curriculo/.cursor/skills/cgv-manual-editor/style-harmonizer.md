# Skill 5 — Style Harmonizer ⭐⭐⭐⭐☆

Ensures every page sounds like it was written by the same editor with the same CGV voice.

## Job

One voice across the manual:

Simple. Elegant. Natural. Educational.

Fifth-grade readability.

Never childish.

Never academic.

Never verbose.

Never repetitive.

## Pass / fail

| Pass | Fail |
|---|---|
| Sounds like a careful guide beside the student | Sounds like a parse report, sermon, or textbook |
| Rhythm varies; openers vary | Every comment same mold |
| Short sentences; clear Spanish (LatAm) | Dense, abstract, or anglicized prose |
| Warm without hype | Emotional language to force excitement |
| Fits the surrounding units | Voice jumps unit to unit |

## Checklist

- [ ] Spanish: simple, natural, educational — not academic, not childish.
- [ ] No hype / no forced drama.
- [ ] Openers are not stuck on *El texto…* / *El autor…* / *La línea…*.
- [ ] This unit would not embarrass the units before and after for tone.
- [ ] Shortening improved clarity — it did not flatten voice into telegrams.

## Harmonize with (do not reopen)

- Escriba craft already in the manuscript (purpose-per-`>`, underlines, slide blanks)
- Locked Scripture and ROOTS lines
- The book’s established address (*hijitos*, *amados*, etc.) when the text uses it

## Rewrite moves

1. Prefer spoken clarity over formal padding.
2. Break long sentences; keep one breath per `>` block.
3. Replace interchangeable boilerplate with wording that belongs to *this* line.
4. Cut emotional intensifiers that the author did not earn.

## Success line

The page sounds like **one CGV editor** helped the student read the author — not like five voices arguing.
