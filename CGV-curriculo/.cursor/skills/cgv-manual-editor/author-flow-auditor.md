# Skill 2 — Author Flow Auditor ⭐⭐⭐⭐⭐

Checks whether the manual preserves the author's pace and doesn't resolve tensions too early.

## Job

Protect the biblical author's order.

If the author leaves tension unresolved, **leave it unresolved**.

Never answer early.

## Pass / fail

| Pass | Fail |
|---|---|
| Pressure stays open until Scripture closes it | Comment resolves the “si…”, purpose, or contrast early |
| Student still wonders what the next line will do | Student feels the case is closed mid-unit |
| Comment names *what is not yet said* without filling it | Comment supplies the missing doctrine or application |
| Pace matches the author's breath | Comment rushes, summarizes ahead, or harmonizes |

## Checklist

- [ ] Does this comment preserve the author's pace?
- [ ] Is any question answered before the author answers it?
- [ ] Did I summarize something the reader has not yet observed?
- [ ] Did I resolve a tension the next clause (or later stretch) still holds?
- [ ] Would this comment help the student read the *next* paragraph better — without spoiling it?

## Editorial questions (flow)

What changed from the previous clause?

Why did the author put this here?

What question is the author creating?

What should the student still be wondering?

## Rewrite moves

1. Convert early answers into open pressure (*Todavía no…* / *Eso llega…* only when the text earns the delay).
2. Delete spoilers that borrow from later verses.
3. Prefer movement (*why here*) over conclusion (*what this means for us*).

## Success line

The student says: **“I see what the author is doing.”** — still following, not finished for them.
