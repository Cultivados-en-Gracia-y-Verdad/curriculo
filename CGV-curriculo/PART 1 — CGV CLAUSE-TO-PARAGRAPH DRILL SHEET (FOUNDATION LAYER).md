# PART 1 — CGV CLAUSE-TO-PARAGRAPH DRILL SHEET (FOUNDATION LAYER)

This is not a manual.
 This is an internal reliability sheet.

Clean. Mechanical. Repeatable.

------

## CGV STRUCTURE DRILL — LEVEL 1

### Purpose

To establish structural control before interpretation.

This drill must be completed before any theological discussion.

------

# SECTION A — Clause Control

### Step 1 — Identify Subordinators

Mark all subordinate markers:

- if
- when
- while
- because
- although
- since
- after
- before
- that (content clause)
- who / which / that (relative)
- what (indirect question)
- participles (-ing / having…)

Write out full subordinate units.
 Do not cut them short.

------

### Step 2 — Identify Anchor Clauses

Remove subordinate units.

What remains are anchor clauses.

Write each anchor clause fully.

Important:

- There may be more than one.
- Coordination (and, but, or) joins equals.
- Do not confuse discourse connectors (“for,” “therefore”) with subordinators.

Anchor ≠ theological center
 Anchor = structural controller

------

### Step 3 — List Anchor Verbs

From the anchor clauses, list the anchor verbs in order.

Example format:

v22 – prove
 v23 – is
 v24 – looked / gone / forgotten
 v25 – will be
 v26 – is

This becomes the paragraph skeleton.

------

# SECTION B — Anchor Sequence Mapping

Read only the anchor clauses in order.

Do not reread the full paragraph yet.

Label the sentence-level function of each anchor clause:

Possible functions:

- Command
- Assertion
- Evaluation
- Comparison
- Illustration
- Explanation
- Promise
- Warning
- Question
- Conclusion
- Development
- Contrast

Keep labels simple and mechanical.

------

# SECTION C — Movement Pattern

Describe the paragraph movement in one structural sentence.

Examples:

- Command → Illustration → Negative Outcome → Positive Contrast
- Assertion → Grounding → Result
- Condition → Evaluation
- Question → Answer

No theology.
 No application.
 Just movement.

------

# SECTION D — Stability Check

Before interpretation, confirm:

☐ All subordinate units identified
 ☐ All anchor clauses identified
 ☐ All coordination recognized
 ☐ Anchor sequence listed
 ☐ Movement pattern described

If any are unclear, interpretation is not permitted.

------

# Paragraph Thesis Extraction

Important:

Thesis ≠ theological system
 Thesis ≠ favorite verse
 Thesis ≠ most quoted idea

Thesis = the controlling assertion that governs the movement of the paragraph.

And here’s the key:

Thesis must be derived from anchor sequence.

Not from intuition.

------

## Step 1 — Look for Structural Dominance

Ask:

Which anchor clause controls the others?

Often it will be:

- A command (followed by illustration)
- A main assertion (followed by grounding)
- A question (followed by answer)
- A warning (followed by reason)

The thesis is usually:

The anchor clause that the rest of the paragraph supports or explains.

------

## Step 2 — Test the Support Flow

Ask:

Which anchor clauses explain or illustrate another anchor clause?

That anchor is likely dominant.

Example: James 1:22–26

Command → Illustration → Explanation → Positive contrast → Negative evaluation

The dominant clause is likely:
 “prove yourselves doers of the word.”

Everything else supports that command.

------

## Step 3 — Write a Minimal Thesis

One sentence.
 Plain language.
 Derived from structure.

Not theology.
 Not abstraction.

Example (James 1:22–26 structural thesis):

“You must be doers of the word, not hearers only.”

Everything else develops that.



### Paragraph Thesis Extraction Rule

The thesis is the anchor clause that:

- The remaining anchor clauses support, illustrate, contrast, or evaluate.
- If removed, causes the rest of the paragraph to lose structural coherence.
