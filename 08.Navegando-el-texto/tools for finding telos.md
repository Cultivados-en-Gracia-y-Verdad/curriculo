# A practical worksheet

When studying a paragraph:

```
1. ¿Cuál es la presión?

2. ¿Qué revela?

3. ¿Qué contraste aparece?

4. ¿Qué orientación recibe aprobación?

5. ¿Qué resultado produce?

6. ¿Cómo encaja esto con el resto del libro?
```





# Tool 1 — Pressure Detector

Pressure is usually introduced when a stable situation is disturbed.

Look for:

## A. Condition clauses

```
if
when
whenever
should
suppose
```

Examples:

```
when you encounter various trials
if any of you lacks wisdom
if a brother or sister lacks clothing
```

These often introduce pressure.

------

## B. Lack language

```
lacks
without
need
poor
hungry
naked
```

Pressure often appears as deficiency.

------

## C. Conflict language

```
wars
quarrels
opposition
temptation
persecution
```

Pressure often enters through conflict.

------

## D. Testing language

```
trial
testing
temptation
prove
examine
```

These are obvious pressure markers.

------

# Mechanical question

Ask:

> What is disturbing the equilibrium?

That disturbance is usually the pressure.

------

# Tool 2 — Revelation Detector

Pressure alone is not enough.

Ask:

> What becomes visible because of the pressure?

Look for:

## A. Verbs of manifestation

```
show
see
appear
reveal
demonstrate
```

James 2 is full of these.

------

## B. Evaluative labels

```
double-minded
wise
foolish
dead
perfect
useless
```

These often reveal what the author thinks the pressure exposed.

------

## C. Contrast pairs

```
hearer / doer

rich / poor

wisdom above / wisdom below

faith / works
```

Contrasts often reveal the hidden issue.

------

# Mechanical question

Ask:

> What does the author now know that was not visible before the pressure arrived?

That is often the revelation.

------

# Tool 3 — Outcome Detector

This is probably the easiest.

Look for result language.

## A. Explicit result verbs

```
produce
lead to
bring forth
result in
become
grow
perfect
die
```

James loves these.

------

## B. Final evaluations

```
dead
perfect
complete
useless
blessed
friend of God
```

These are outcome markers.

------

## C. Telic grammar

Things like:

```
so that
in order that
until
perfect
complete
crown
death
```

These often point toward the destination.

------

# Mechanical question

Ask:

> Where does this path end?

That endpoint is usually the outcome.

------

# Visual Framework

Once identified:

```
PRESSURE
↓
REVELATION
↓
OUTCOME
```

Example:

```
trial
↓
perseverance
↓
complete
```

Example:

```
temptation
↓
desire exposed
↓
death
```

Example:

```
needy brother
↓
faith revealed
↓
dead or perfected
```

------

# The hardest problem

Pressure is usually explicit.

Outcome is often explicit.

Revelation is often hidden.

So I would teach students:

```
1. Find the pressure.

2. Find the outcome.

3. Ask:

   What must have been revealed
   for the author to arrive
   at that outcome?
```

This is often easier than starting with revelation.

For Santiago 2:

```
Pressure:
Brother in need

Outcome:
Dead faith
or
Perfected faith

Revelation:
The actual condition
of the claimed faith
becomes visible.
```

That is the sort of mechanical pathway that can eventually become a repeatable ROOTS-style tool rather than merely an insightful observation.
