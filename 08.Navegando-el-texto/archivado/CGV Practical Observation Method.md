# CGV Practical Observation Method

### (For Navigating the Bible Text)

Two parts.

Clear.
 Transferable.
 Mechanically testable.

------

# PART 1 — What H1, H2, and H3 Mean

This section defines roles. No application yet.

------

## H3 — The Text Itself

- H3 is the verse reference and text.
- It has final authority.
- It cannot be adjusted to fit H1 or H2.
- It does not summarize.
- It does not interpret.
- It simply presents what is written.

H3 is fixed.
 Everything else must answer to it.

------

## H2 — The Internal Development

- H2 identifies how the argument develops inside a movement.
- It follows the flow of thought.
- It marks natural pivots.
- It does not summarize doctrine.
- It does not introduce theological systems.

H2 describes what is happening in the development.

If H2 cannot be supported directly by H3, it is wrong.

------

## H1 — The Major Movement

- H1 identifies what the author is doing in a larger section.
- It is action-oriented (confronts, defends, argues, warns, instructs).
- It is not a doctrinal slogan.
- It is not a theological category.

H1 must arise from the cumulative force of H2.

If H2 does not naturally support H1, H1 must be revised.

------

# Structural Hierarchy

H3 → supplies evidence
 H2 → organizes development
 H1 → describes the macro action

Validation runs in reverse:

H3 must confirm H2.
 H2 must confirm H1.

If that chain breaks, the structure is wrong.

------

That is Part 1: Definitions.

Now Part 2 is where training happens.

------

# PART 2 — How to Determine H1, H2, and H3

This must be mechanical.

Not intuitive.
 Not aesthetic.
 Not theological.

------

## Step 1 — Read the Whole Section Without Dividing

Ask only:

What is the author doing?

Not:
 What doctrine is here?

But:
 Is he confronting?
 Defending?
 Explaining?
 Commanding?
 Warning?

That becomes your provisional H1.

It is a hypothesis.

------

## Step 2 — Break by Natural Development (H2)

Look for:

- New questions introduced
- Shifts in tone
- Change in rhetorical mode (argument → appeal → illustration)
- Direct pivots (“pero”, “entonces”, “¿para qué?”, etc.)
- Escalations in intensity

Each must be visible in the text.

If you cannot point to a clear shift in the text, do not divide.

------

## Step 3 — Test Every H2 Against H3

Ask:

Does this heading describe what is actually happening in these verses?

If it requires outside explanation, it fails.

If it summarizes theology instead of development, it fails.

If it imports categories not present in the verses, it fails.

------

## Step 4 — Reverse Validation

Now test upward:

Does the collection of H2 naturally support the H1 action?

If not, either:

- H1 is wrong.
- H2 divisions are wrong.
- Or both.

Revise.

------

## Step 5 — Warning Signs of Structural Bias

Do not divide because:

- A key word appears.
- A doctrine is mentioned.
- A commentary suggests it.
- A chapter division exists.

Divide only where development shifts.

------

## Step 6 — Final Check

If you removed H1 and H2 and simply read H3,
 would the structure feel forced?

If yes, revise.

Structure must feel discovered, not imposed.



# How to Divide Only Where Development Shifts

This is not intuitive.
 It must be mechanical.

------

## 1. What Is a Development Shift?

A development shift occurs when the author changes:

- The rhetorical mode
- The argumentative direction
- The tone or intensity
- The controlling question
- The primary contrast
- The relational posture

It is not merely:

- A new illustration
- A repeated word
- A new example inside the same argument

------

## 2. Five Mechanical Indicators of a Real Shift

When reading a passage, ask:

### A. Does a new question drive the section?

Example:
 “¿Para qué fue dada la ley?”

That signals a new stage in the argument.

If the question changes, the development has shifted.

------

### B. Does the author change mode?

Common shifts:

- Argument → Appeal
- Appeal → Warning
- Illustration → Application
- Defense → Command

If the mode changes, mark it.

------

### C. Does the dominant contrast change?

Example:

Flesh vs Spirit
 →
 Community restoration instructions

That is not minor variation.
 That is structural shift.

------

### D. Does the tone escalate or pivot?

Examples:

- Calm explanation → Urgent warning
- General teaching → Direct rebuke
- Narrative → Command

Tone shift often signals development shift.

------

### E. Does the section stand independently?

If removing the previous verses makes the section collapse,
 it is not a new development.

If it can stand on its own argumentative footing,
 it likely is.

------

## 3. What Is NOT a Development Shift?

Do NOT divide because:

- A repeated key word appears.
- A theological theme is introduced.
- The paragraph is long.
- You feel the need for symmetry.
- The chapter number changes.

Those are structural traps.

------

## 4. The Compression Test

Before dividing, ask:

If I combine these verses, does the argument still flow naturally?

If yes, do not divide.

Divide only when combining them blurs the movement.

------

## 5. The Reverse Confirmation Rule

After dividing, run the test backward:

H3 must clearly justify H2.

If H2 cannot be directly demonstrated from the verses,
 it is artificial.

If H2 feels like a summary instead of a development,
 it is wrong.

If H2 serves H1 instead of challenging it,
 it is biased.
