## 🔴 REGLA BASE

```

```

# 📋 CONECTORES PRINCIPALES

------

## 🟠 RAZÓN (¿por qué?)

```
porque  
pues  
ya que
```

👉 Explican la causa

------

## 🔵 PROPÓSITO (¿para qué?)

```
para que
```

👉 Explica la intención

------

## 🟡 CONTRASTE (¿qué se opone?)

```
pero  
mas  
sino
```

👉 Muestra oposición

------

## 🟢 ADICIÓN (¿qué se añade?)

```
y  
también
```

👉 Añade otra cláusula

------

## 🟣 CONDICIÓN (¿bajo qué condición?)

```
si
```

👉 Establece condición

------

## ⚪ TIEMPO (¿cuándo?)

```
cuando  
mientras
```

👉 Marca tiempo

------

## ⚫ DEPENDENCIA (UNE UNA CLÁUSULA A OTRA)

```
que
```

👉 Introduce una cláusula dependiente

------

# ⚠️ CONECTORES COMPUESTOS (IMPORTANTES)

------

## 👉 NO separar

```
para que  
de modo que  
a fin de que
```

👉 Funcionan como UNA unidad

------

# ⚠️ NO USAR EN ESTE PASO (aunque existen)

```
además  
entonces  
así  
en verdad  
como (comparación)  
o (entre frases)
```

👉 No conectan dos verbos directamente

------

# 🧪 PRUEBA FINAL (ESTO ES TODO)

```
¿Une dos verbos?

SI → conector válido  
NO → no se usa  
```
