# 🧠 IMPORTANTÍSIMO (LO QUE EVITA CONFUSIÓN)

## # NO son estructurales

```
como
y
además
también
en verdad
ni aun
no
```

👉 porque NO introducen verbo nuevo
 👉 no crean nueva cláusula
