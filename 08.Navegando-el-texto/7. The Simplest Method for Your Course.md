# 7. The Simplest Method for Your Course

Teach this **3-step mechanical method**.

### Step 1

Find the **finite verb**.

------

### Step 2

Look **left of the verb**.

Closest noun/pronoun usually = **subject**.

------

### Step 3

Look **right of the verb**.

Ask:

**verb + what?**

If it answers → **object**



before moving to the four patterns, i need to understand how object and complement are identified

Good. This is exactly the right place to slow down. If **object vs complement** is not clear, everything later becomes confusing. We can make this **very mechanical**.

------

# 1. The Key Principle

The difference depends on **the type of verb**.

There are two major categories:

| Verb Type        | What Comes After |
| ---------------- | ---------------- |
| **Action verb**  | **Object**       |
| **Linking verb** | **Complement**   |

------

# 2. Action Verb → Object

An **object receives the action** of the verb.

Example:

> I gave milk

Verb: **gave**
 Subject: **I**

Ask the mechanical question:

**gave what?**

Answer:

**milk**

So **milk = object**

------

Another example:

> Paul wrote a letter

Verb: **wrote**

Ask:

**wrote what?**

Answer:

**letter**

Object = **letter**

------

# 3. Linking Verb → Complement

A **linking verb does not perform an action**.
 It **connects the subject to information about the subject**.

Example:

> you are fleshly

Verb: **are**

Ask:

**are what?**

Answer:

**fleshly**

This is **not receiving action**.

It is **describing the subject**.

So **fleshly = complement**.

------

# 4. The Fast Mechanical Test

After the verb ask:

### Test 1

**Does the word receive the action?**

If yes → **Object**

Example:

> gave milk

Milk receives the giving.

------

### Test 2

**Does the word describe or rename the subject?**

If yes → **Complement**

Example:

> you are fleshly

Fleshly describes **you**.

------

# 5. The Substitution Test (Extremely Helpful)

Complements work with **linking verbs**.

Replace the verb with **=**

Example:

> you are fleshly

Becomes:

> you = fleshly

This works.

So **fleshly = complement**.

------

Try it with an object.

> I gave milk

Becomes:

> I = milk

Doesn't work.

So **milk = object**.

------

# 6. Common Linking Verbs

Students should memorize these because they **produce complements**.

Most common in Scripture:

- be (is, are, was, were)
- become
- remain
- seem
- appear

Example:

> God is light

Verb = **is**

Complement = **light**

------

# 7. Object vs Complement Summary

| Example             | Verb Type | Result               |
| ------------------- | --------- | -------------------- |
| I gave milk         | Action    | milk = object        |
| Paul wrote a letter | Action    | letter = object      |
| you are fleshly     | Linking   | fleshly = complement |
| God is light        | Linking   | light = complement   |

------

# 8. Why This Matters For Your Method

When you analyze clauses, you are discovering **the core assertion**.

Example:

> God is light

The assertion is **identity**.

Example:

> Paul wrote a letter

The assertion is **action**.

These are two different **types of statemen**







# 9. Extremely Important Simplification

For your course, students only need to recognize **three possibilities after a verb**:

1. **Object** (receives action)
2. **Complement** (describes subject)
3. **Phrase** (extra information)



Finite verbs vs Infinite verbs.

# 1. What a Finite Verb Is (Simplified)

A **finite verb is the verb that carries the statement**.

It tells us:

- something **happens**
- something **is**
- something **will happen**

Example:

```
God is light
```

**is** = finite verb

------

# 2. The Mechanical Detection Method

Students should run **three quick checks**.

### Check 1 — Does the word change with the subject?

Example:

```
I walk
he walks
```

The verb changes → **finite**

------

### Check 2 — Does the word carry tense?

Example:

```
walk
walked
will walk
```

That word showing tense is the **finite verb**.

------

### Check 3 — Does the word form the core statement?

Example:

```
you are fleshly
```

If you remove **are**, the sentence collapses.

That means **are** is the finite verb.





# 10. Summary Rule for Students

To find the finite verb, ask:

```
What word is making the statement?
```

That word is the **finite verb**.
