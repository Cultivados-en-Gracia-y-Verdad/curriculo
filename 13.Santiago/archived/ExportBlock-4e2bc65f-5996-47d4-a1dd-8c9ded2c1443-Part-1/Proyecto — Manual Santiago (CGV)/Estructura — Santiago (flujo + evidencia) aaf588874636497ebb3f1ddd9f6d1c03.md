# Estructura — Santiago (flujo + evidencia)

## Propósito

Registrar el **flujo** de Santiago y la **evidencia observable** (mecánica + desarrollacional) que justifica la estructura, sin imponer temas.

## Observaciones desarrollacionales (visión del libro completo — borrador)

- 1:2–18: cadenas de producción/resultados; re-entradas (p.ej., “falta”); contraste fe/duda; giro hacia deseo/tentación; restablecimiento.
- 1:19–27: presión sostenida oír/hacer, intensificada por analogía; definición de “religión pura”.
- 2:1–13: contraste rico/pobre instalado por escenario; escalamiento hacia juicio/misericordia.
- 2:14–26: arco probatorio (tensión → re-entrada → escalamiento → cierre).
- 3:1–12: escalamiento por imágenes dentro de una sola presión (lengua).
- 3:13–18: contraste explícito de “sabidurías” y cierre direccional.
- 4:1–10: presión sostenida + reorientación por cadena imperativa.
- 4:11–12: interrupción focal breve (hablar/juzgar).
- 4:13–17: nueva presión (presunción) con cierre de responsabilidad.
- 5:1–6: oráculo de juicio con escalamiento.
- 5:7–11: cambio direccional pastoral a “hermanos”.
- 5:12: cierre puntual.
- 5:13–18: centro común = oración con escalamiento de casos.
- 5:19–20: cierre telegráfico (volver/salvar/cubrir).

## Evidencia mecánica (cómo se registra)

Para cada unidad (y para cada versículo, cuando sea necesario):

- verbos finitos observados
- conectores observados
- movimiento (modo / persona-número) cuando aplique

## Registro de decisiones

Cada decisión de división registra:

1) Presión que continúa

2) Señal observable (re-entrada / cierre demorado / contraste / escalamiento / cambio direccional / resolución)

3) Decisión: cortar / no cortar (y por qué)
