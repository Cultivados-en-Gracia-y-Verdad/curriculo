# ROOTS LEXICON — ENTRY VALIDATION CHECKLIST

------

## 1. HEADER VALIDATION

### 1.1 Lemma present and correct

-  Greek lemma is accurate (SBLGNT-aligned)
-  Lemma is not an inflected form

------

### 1.2 Strong’s number correct

-  Strong’s matches the lemma
-  One lemma → one Strong’s (no duplication)
-  Strong’s is visible in header

------

### 1.3 Format correct

-  Format is:

```
### lemma — G####
```

------

## 2. GLOSA VALIDATION

### 2.1 Single primary gloss

-  One Spanish word only
-  No synonym lists

------

### 2.2 Consistency

-  Same gloss used across entire lexicon
-  Matches prior entries for same lemma

------

### 2.3 NBLA alignment (if applicable)

-  Gloss aligns with NBLA where accurate
-  Not forced if NBLA is inconsistent

------

## 3. DEFINICIÓN (ROOTS)

### 3.1 Structure

-  One sentence
-  6–12 words (flexible but controlled)

------

### 3.2 Content

-  Describes observable linguistic function
-  No theological language
-  No interpretation

------

### 3.3 Independence

-  Not copied or translated from lexicons
-  Wording is original

------

### 3.4 Precision

-  Not vague (no “algo”, “varios”, etc.)
-  Not overly broad
-  Clearly tied to lemma

------

## 4. RANGO SEMÁNTICO

### 4.1 Coverage

-  Reflects real range of usage
-  Includes distinct semantic possibilities

------

### 4.2 Discipline

-  No interpretation
-  No theological framing
-  No speculative meanings

------

### 4.3 Clarity

-  Each bullet is distinct
-  No repetition from definition

------

## 5. USO EN EL NT

### 5.1 Observability

-  Describes how the word is used in the NT
-  Based on patterns, not interpretation

------

### 5.2 Restrictions

-  No verse lists (unless system changes later)
-  No doctrinal conclusions

------

### 5.3 Precision

-  Each bullet reflects a real usage pattern
-  No vague generalizations

------

## 6. USO EN GRIEGO DEL SIGLO I

### 6.1 Historical grounding

-  Consistent with koiné usage
-  No speculative historical claims

------

### 6.2 Scope

-  Describes general usage environment
-  Not NT-only statements

------

### 6.3 Discipline

-  No theology
-  No overstatement (“always”, “never”)

------

## 7. FUNDAMENTO LÉXICO

### 7.1 Content

-  Reflects linguistic grounding
-  Summarizes semantic behavior

------

### 7.2 Restrictions

-  No naming sources (BDAG, LSJ, etc.)
-  No quotations

------

### 7.3 Function

-  Supports the definition logically
-  Does not repeat earlier sections

------

## 8. NON-THEOLOGICAL CONTROL (GLOBAL CHECK)

-  No doctrinal terms
-  No interpretive conclusions
-  No system-based theology

------

## 9. CONSISTENCY CHECK (GLOBAL)

-  Matches tone of existing entries
-  Matches structure exactly
-  No deviation in section names

------

## 10. REDUNDANCY CHECK

-  No repeated phrases across sections
-  Each section adds new information

------

## 11. LANGUAGE QUALITY

-  Clear Spanish
-  No ambiguity
-  No unnecessary complexity

------

## 12. FINAL APPROVAL TEST

Ask:

👉 Can this entry be used in ROOTS without interpretation?

-  YES → Accept
-  NO → Revise
