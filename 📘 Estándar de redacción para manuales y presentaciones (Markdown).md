## 📘 Estándar de redacción para manuales y presentaciones (Markdown)

Este manual utiliza **Markdown** como base para producir **presentaciones** y **material escrito (PDF)**.
 Para que ambos funcionen correctamente, **cada elemento cumple una función específica**.

------

## 1️⃣ Encabezados (Títulos)

Los encabezados se usan **solo para estructura**, no para énfasis visual.

### Uso

```
#### Encabezado principal
```

### Regla

- Los encabezados **definen secciones**
- Controlan la **estructura del contenido**
- **No** se usan para definiciones, palabras clave ni frases sueltas

### ❌ No usar encabezados para:

- Palabras individuales
- Definiciones
- Frases breves de énfasis
- Controlar diapositivas

------

## 2️⃣ Anotaciones inmediatas (debajo del encabezado)

Cuando se necesita una línea **justo debajo del encabezado**, sin espacio y en la **misma diapositiva**, se usa **cita en bloque**.

### Uso correcto

```
#### Encabezado principal
> Línea aclaratoria o explicativa inmediata.
```

### Regla

- La cita (`>`) **no crea una nueva sección**
- Permite varias líneas seguidas sin espacio
- Se mantiene unida visualmente al encabezado

### Ejemplo

```
#### No se refiere a pasividad o debilidad.
> Se refiere a soportar sin reaccionar impulsivamente.
```

------

## 3️⃣ Definiciones (uso preferido)

Las **definiciones** deben tener una forma **clara y consistente**.

### ✅ Forma preferida: Lista de definiciones

```
Paciencia
: Capacidad de soportar sin reaccionar impulsivamente; tolerancia estable.
```

### Regla

- El término va solo
- La definición va debajo
- No se usa encabezado
- No se usa lista con viñetas

Esta forma es:

- Clara para el lector
- Estable para PDF
- Compatible con presentaciones

------

## 4️⃣ Definiciones (forma alternativa)

Si el sistema de presentación no admite listas de definición:

```
**Paciencia:** Capacidad de soportar sin reaccionar impulsivamente; tolerancia estable.
```

⚠️ Esta forma es válida, pero **menos estructural** que la preferida.

------

## 5️⃣ Listas (enumeración real)

Las listas se usan **solo cuando hay una enumeración real**.

### Uso correcto

```
- Primer punto
- Segundo punto
- Tercer punto
```

o

```
1. Primer punto
2. Segundo punto
3. Tercer punto
```

### ❌ No usar listas para:

- Definiciones
- Frases de énfasis
- Anotaciones debajo de encabezados

------

## 6️⃣ Control de diapositivas

En el sistema de presentación:

- **Una línea en blanco = nueva diapositiva**
- Líneas consecutivas sin espacio permanecen en la misma diapositiva

Por eso:

- **No se insertan líneas en blanco innecesarias**
- Se usan citas (`>`) para mantener líneas juntas

------

## 🧭 Resumen rápido (para recordar)

| Propósito                | Qué usar                |
| ------------------------ | ----------------------- |
| Estructura               | `#### Encabezado`       |
| Aclaración inmediata     | `> Cita`                |
| Definición (preferida)   | Lista de definición     |
| Definición (alternativa) | **Término:** definición |
| Enumeración              | Listas                  |
| Nueva diapositiva        | Línea en blanco         |

------

## 📌 Regla de oro

> **Encabezados estructuran.
>  Citas aclaran.
>  Definiciones definen.
>  Listas enumeran.**

Si cada cosa cumple su función, el material:

- se ve limpio
- se proyecta bien
- se imprime correctamente
- y se mantiene consistente entre docentes
