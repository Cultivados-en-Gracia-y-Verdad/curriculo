# Discourse vs chronology audit — Apocalipsis 15:1–16:21

**Scope:** full H2 remap (subsections A–G).

| Pattern | Verdict |
|---|---|
| `Καὶ εἶδον` / `Καὶ ἤκουσα` (15:1–2, 16:1, 5, 7, 13) | KEEP — Juan testigo donde Greek tiene εἶδον/ἤκουσα |
| `Μετὰ ταῦτα εἶδον` (15:5) | KEEP — secuencia textual, no calendario |
| `ἕως τελεσθῶσιν` (15:8) | KEEP — límite hasta completar plagas |
| Copa tras copa (16:2–21) | KEEP — serie ordinal del texto, no *luego* inventado |
| `οὐ μετενόησαν` (16:9, 11, 21) | KEEP — patrón moral; enlace 9:20–21 |
| Inserción 16:15 entre 14–16 | KEEP — orden del manuscrito; no reordenar |
| `συνήγαγεν` (16:16) | KEEP — resultado textual; En síntesis sin *Luego* |
| `Γέγονεν` (16:17) | KEEP — declaración desde el trono |
| `ἐμνήσθη… Βαβυλών` (16:19) | KEEP — enlace con 14:8; no cronología externa |
| Primera persona `ἔρχομαι` (16:15) | KEEP — verbo lleva persona; no *Yo, Juan* |
| No `*Yo, Juan*` sin `ἐγώ` | KEEP |

**Unsupported event chronology:** none.

**En síntesis:** *Luego* antes de Armagedón → removed.
