README — Bible Study Textual Base (Update)
Primary Greek Textual Sources
1. Default Critical Text
Nestle–Aland Greek New Testament, 28th Edition (NA28)
Used as the default textual base for New Testament study when available.
Observations must remain strictly text-bound to the Greek text.
2. Authorized Working Manuscript (When NA28 Is Not Directly Accessible)
SBL Greek New Testament (SBLGNT) — hosted locally on this site:
Copy code

https://johnwry.github.io/bible-study/docs/sblgnt-txt/
This hosted SBLGNT corpus functions as the authoritative working manuscript for:
grammatical observation
discourse analysis
structural and cycle mapping
concordance-style word and phrase tracing
All quotations, observations, and demonstrations must be:
taken directly from the hosted SBLGNT text
cited by book, chapter, and verse
treated as the fixed textual reference point for the study
3. Relationship Between NA28 and SBLGNT
SBLGNT is used as a legal, stable, machine-readable critical text.
Where textual differences between NA28 and SBLGNT exist:
observations remain valid unless a variant materially affects the grammatical or discourse feature under discussion
variants may be noted only when relevant, without theological synthesis
🔍 Methodological Commitment (Clarification)
All structural claims (cycles, divisions, tests, security statements, etc.) must be:
demonstrable directly from the Greek text
supported by visible discourse markers (e.g., vocatives, formula phrases, restart cues)
not imposed by theology, tradition, or external frameworks
When structure is proposed, the study must show:
where the unit begins textually
how the unit resolves textually
why the boundary is warranted from the manuscript itself
✅ Summary Rule (For Quick Reference)
When NA28 is not directly accessible, all New Testament analysis must anchor explicitly to the hosted SBLGNT text at johnwry.github.io/bible-study/docs/sblgnt-txt/, quoting and observing the Greek manuscript itself.
