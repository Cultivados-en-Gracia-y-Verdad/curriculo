## Lo que este script NO puede ver

No trate un reporte sin hallazgos como una aprobación. Este script no puede juzgar:

- si una cláusula marcada independiente realmente lo es
- si falta un independiente (un imperativo enterrado en `-` o `+`)
- si un comentario interpreta en vez de observar
- si un H1 es cierto de todos sus H2, o si los rangos teselan el libro
- si una forma hebrea, aramea o griega está bien nombrada
- si una afirmación histórica es defendible
- si el telos fue fabricado
- cobertura palabra por palabra: compara palabras de contenido (≥4 letras) contra
  todo el manual, así que una palabra movida al versículo equivocado no se detecta

Esas preguntas son de Editor → Verificador → especialistas → Arquitecto,
y ninguna se cierra sin que un humano lea la superficie.
